# #9 — Add --version flag to flowstate export

**Problem:** Profile version is hardcoded to `1.0.0` in `build_profile()`. Users publishing updated profiles need to set the version without manually editing the JSON.

**Current behavior:** `build_profile()` in `export_cmd.py:161` accepts a `version` parameter (default `"1.0.0"`) but `run_export()` doesn't expose it and the CLI has no `--version` flag.

**Expected behavior:** `flowstate export --version 2.1.0` sets `profile["version"]` to `"2.1.0"`. Default remains `1.0.0`.

**Edge cases:**
- No validation on version format (semver not enforced — matches existing schema which only checks non-empty string)
- Empty string should error (already handled by schema validation)

**Test plan:**
- Unit: `test_build_profile_custom_version` — verify version field in output
- Integration: `test_run_export_custom_version` — verify version flows through run_export

**Scope:**
- In: Add `--version` arg to CLI, wire through `cmd_export` → `run_export` → `build_profile`
- Out: Semver validation, auto-increment logic
