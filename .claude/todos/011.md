# #11 — Rename project from flowstate to flow-state

**Problem:** The name "flowstate" doesn't communicate the tool's purpose. "flow-state" better conveys the goal: reducing prompt fatigue so developers stay in flow.

**Current behavior:** The package is named `flowstate` everywhere — `src/flow_state/`, CLI entry point `flowstate`, pyproject.toml package name, CLAUDE.md references, plugin directory `plugins/flow-state/`, test references, import paths.

**Expected behavior:** After rename:
- Package: `flow-state` (PyPI-style) / `flow_state` (Python module)
- CLI command: `flowstate` (no hyphen for ergonomics) or `flow-state` — [TBD: decide CLI name]
- Source: `src/flow_state/`
- Plugin dir: `plugins/flow-state/`
- All imports, test references, CLAUDE.md, README updated
- Git history preserved (no squash — keep the rename as a single commit)

**Edge cases:**
- Existing installs: users with `flowstate` in their PATH need migration guidance
- Plugin references in `hooks.json` or `settings.json` need updating
- Lock file paths (`~/.claude/hooks/`) are unchanged (they reference `permission-config.json`, not the package name)
- PyPI name availability — check before committing to the name

**Test plan:**
- All 380+ existing tests pass with new import paths
- `flowstate --help` works
- Plugin install still registers hooks correctly
- `uv run python -m pytest tests/ -v` green

**Scope:**
- IN: Full rename of package, CLI, imports, docs, plugin dir
- OUT: No functional changes. Pure rename.
