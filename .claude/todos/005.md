# #5 — Interactive tier selection prompt in flowstate setup

**Problem:** Design doc specifies a 3-option interactive menu during `flowstate setup`. Currently only `--tier` CLI flag works.

**Current behavior:** `run_setup()` accepts `tier` parameter (default "balanced"). No interactive prompt shown.

**Expected behavior:** When `interactive=True` and no `--tier` flag, show Cautious/Balanced/Flow menu with descriptions. `--tier` or `--yes` skips the prompt.

**Edge cases:**
- `--tier` provided: skip prompt
- `--yes`: skip prompt, use balanced
- Invalid input: re-prompt
- Non-interactive (tests): skip, use default

**Test plan:**
- Unit test with mocked input: tier selection flows to `generate_config()`
- Unit test: `--tier flow` skips prompt
- Unit test: `--yes` skips prompt

**Scope:** `setup_cmd.py` prompt logic and `cli.py` arg handling only.
