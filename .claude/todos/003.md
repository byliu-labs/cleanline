# #3 — Tier downgrade suggestions in tighten

**Problem:** If a user is on "flow" tier but most flow-specific rules have never triggered, `tighten` should suggest downgrading to "balanced". Closes the feedback loop: setup -> audit -> tighten -> tier suggestion.

**Current behavior:** `tighten` detects stale individual rules but has no concept of tier-level staleness.

**Expected behavior:** After analyzing individual rule staleness, if >80% of tier-specific rules are stale, suggest: "Consider: flowstate setup --tier balanced"

**Edge cases:**
- Cautious tier: no downgrade possible, skip
- Profile rules that need the higher tier: warn but don't push

**Test plan:**
- Unit test: flow user with 90% stale flow-specific rules -> downgrade suggestion
- Unit test: flow user with 50% stale -> no suggestion
- Unit test: cautious user -> no tier suggestion

**Scope:** `tighten.py` analysis + `cli.py` formatting. Advisory only, no automatic changes.
