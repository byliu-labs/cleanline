# #8 — flowstate clean: extend to Read/Edit/Write/Glob/Grep path entries

**Problem:** `flowstate clean` currently only analyzes Bash(...) entries in the settings.json allow list. Users also accumulate redundant file access entries like `Read(src/main.py)` when `Read(src/**)` already covers it, or multiple specific `Edit(...)` entries that could consolidate into a wildcard.

**Current behavior:** `clean_cmd.py` parses only `Bash(...)` entries via `_BASH_ENTRY` regex. `Read(...)`, `Edit(...)`, `Write(...)`, `Glob(...)`, `Grep(...)` entries are silently skipped — no redundancy detection, no consolidation proposals.

**Expected behavior:**
- Detect redundant file path entries: `Read(src/main.py)` is redundant when `Read(src/**)` exists
- Detect cross-tool redundancy: `Glob(src/**)` redundant when `Read(src/**)` exists (Read implies Glob access)
- Propose consolidations: 3+ specific `Read(src/components/Foo.tsx)`, `Read(src/components/Bar.tsx)`, etc. → `Read(src/components/*)`
- Respect tool hierarchy: Read/Glob/Grep are read operations; Edit/Write are write operations. Don't suggest consolidating across read/write boundaries.

**Edge cases:**
- Glob patterns with `**` vs `*` (recursive vs single-level)
- Entries with `~` home dir prefix vs absolute paths
- Mixed tool types: `Read(src/**)` + `Glob(src/**)` — should flag Glob as redundant (Read covers Glob's access)
- `Write(*.py)` — wildcard at root level, covers all Python files
- Path entries without wildcards: `Read(CLAUDE.md)` — specific file, consolidation candidate

**Test plan:**
- Unit tests for `find_redundant_file_entries()` with same-tool and cross-tool cases
- Unit tests for `find_file_consolidations()` with directory-level grouping
- Integration tests for `analyze_allow_list()` returning both Bash and file path results
- Test that `apply_clean()` correctly removes file path entries and adds wildcard replacements

**Scope:**
- IN: Redundancy detection for file path entries, consolidation proposals, integrate into existing analyze/apply flow
- OUT: Deny list analysis, cross-referencing with flowstate fileAccess config, modifying hook behavior
